# 지하도시 RTS × 3인칭 액션 (moong)

지하도시를 배경으로 한 소규모 전술 게임입니다. 평소에는 RTS처럼 분대를 지휘하다가, 원하는 유닛에 **빙의**해서 3인칭으로 직접 싸울 수 있습니다. 브라우저에서 바로 실행되며 설치가 필요 없습니다.

**▶ 플레이: https://suncreation.github.io/moong/**

## 목표
붉은 적 기지를 파괴하세요. 아군 기지가 파괴되거나 분대가 전멸하면 패배합니다. 시간이 지날수록 **위기도**가 올라 적이 더 강하고 더 자주 몰려옵니다.

## 조작

| | |
|---|---|
| **RTS 모드** | 좌클릭/드래그 선택 · 우클릭 이동·공격 · `WASD` 카메라 이동 · `Q/E` 카메라 회전 · 휠 줌 |
| **빙의 (3인칭)** | `Tab` 빙의 토글 · `1~6` 해당 유닛으로 즉시 빙의 · `WASD` 이동 · 마우스로 시점/조준 (클릭하면 고정) · 좌클릭 공격 |
| **전투** | `Space` 점프 · `Shift` 대시(무적, 공격 후딜 캔슬) · `Q/E` 고유 스킬 · `C` 웅크리기(엄폐) · `T` 조준 보정 |
| **기타** | `F` 전원 선택 · `Esc` 빙의 해제 · `H` 도움말 · `R` 재시작(게임 오버 시) |

## 유닛
- **영웅(검)** 3연 콤보 · 충격파 · 과부하
- **중장갑(망치)** 방벽 · 돌진
- **암살자(단검)** 암습(등 뒤 순간이동) · 그림자(은신)
- **마법사** 마법탄 · 얼음 장판 · 번개 연쇄
- **소총병 ×2** 총 · 수류탄 · 관통 저격

## 알아둘 점
- 낮은 방벽 뒤에서 웅크리면 탄을 막지만, 사격하면 잠깐 노출됩니다.
- 대시 직후의 근접 공격은 강화됩니다. 적 검사·중장은 공격 직전에 몸이 밝아지니 그때 대시로 피하세요.
- 적 저격수는 **붉은 레이저로 조준**한 뒤 쏩니다. 레이저가 보이면 움직이거나 대시하세요.
- 적은 길을 찾아 층과 경사로를 오르고, 엄폐하고, 물러나며 쏘고, 협공합니다.

## 기술
Three.js 하나로 만든 단일 HTML 파일(`index.html`)입니다. 라이브러리는 CDN(unpkg)에서 불러오므로 인터넷 연결이 필요합니다.

로컬 실행: 파일을 브라우저로 열거나 `python3 -m http.server` 후 `http://localhost:8000` 접속.
